**Download `trim-c-*-win-x64.zip`, extract it anywhere and run `trim-c.exe`.** Nothing else is needed: the .NET runtime, FFmpeg and libmpv are included.

**`trim-c-*-win-x64.zip` dosyasını indir, istediğin bir klasöre çıkar ve `trim-c.exe` dosyasını çalıştır.** Başka hiçbir şey kurman gerekmez: .NET çalışma ortamı, FFmpeg ve libmpv pakete dahildir.

Windows 10 or 11, 64-bit. See the [README](https://github.com/toprakgureli/trim-c#readme) for usage and [THIRD-PARTY-NOTICES.md](https://github.com/toprakgureli/trim-c/blob/main/THIRD-PARTY-NOTICES.md) for the licenses of the included components.
